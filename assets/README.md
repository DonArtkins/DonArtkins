# Assets Folder

This folder contains visual assets for the Lyncxs City profile.

## Required Assets

### `city-skyline.gif`
- **Description:** Animated city skyline showing Lyncxs tech metropolis
- **Dimensions:** 1200x400px recommended
- **Format:** GIF (animated) or static image
- **Theme:** Dark mode, neon/tech aesthetic
- **Colors:** Match brand (indigo #6366F1, emerald #10B981, amber #F59E0B, purple #8B5CF6)

### Temporary Placeholder

Until you add a custom city skyline, the profile will use a text banner or you can:

1. **Use a free city skyline generator:**
   - https://www.canva.com (search "tech city skyline")
   - https://www.remove.bg (remove backgrounds)
   - https://ezgif.com (create animations)

2. **Commission a custom one:**
   - Fiverr artists
   - 99designs
   - Local designers

3. **Use a stock image temporarily:**
   - Unsplash, Pexels (CC0 license)
   - Add "Lyncxs City" text overlay

## Creating Your City Skyline

**Concept:** Visualize Lyncxs as a futuristic tech city with 4 distinct districts:

```
🤖 AI Quarter (Blue towers) - Left side
🛠️ Tools District (Green buildings) - Center-left
🏛️ Business Hub (Amber skyscrapers) - Center-right
📚 Knowledge Vault (Purple structures) - Right side
```

**Style:** Neon, cyberpunk, tech-forward, African elements

## Adding the Asset

Once you have `city-skyline.gif`:

```bash
# Place it here
cp /path/to/your/city-skyline.gif ./city-skyline.gif

# Or directly in this folder
# github-setup-2026/premium-profiles/DonArtkins/assets/city-skyline.gif
```

The README.md already references it as `./assets/city-skyline.gif`
